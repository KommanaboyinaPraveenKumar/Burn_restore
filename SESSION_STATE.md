## 1. Project Overview & Objective
* **Goal:** Line-Grounded Side-Burnt Document Text Restoration using a cross-modal architecture (`ForensicT5Restorer`).
* **Stream A (Full-Page Context Engine & Seq2Seq):** Pretrained `t5-small` encoding the full surviving document context paired with the surviving line prefix prompt (`restore line | page: <context> | prefix: <prefix>`).
* **Stream B (High-Res Forensic Eye):** High-resolution `resnet34` processing local $128 \times 256$ line crops centered on the line's burn edge (where glyphs are 35px tall and ink ghost strokes are physically resolved).
* **Multimodal Prefix Fusion:** Spatial visual ghost tokens are projected and prepended to the T5 encoder memory, allowing the T5 autoregressive decoder to simultaneously condition on linguistic semantics and visual ink remnants to rank and emit the exact severed line ending.

## 4. Key Fixes Applied So Far
1. **Geometric OCR Clustering:** Fixed raw TSV coordinates corruption by grouping words into natural lines (`preprocess_oprb.py`).
2. **Eliminated Resolution Smudge:** Replaced 4-pixel squashed 256px page crops with focused line-level crops ($128 \times 256$) where glyphs are 35px tall and ink ghost strokes are physically preserved.
3. **Eliminated Multi-Line Target Concatenation Mismatch:** Refactored architecture from multi-line sequence squashing to line-grounded restoration: `[Full Page Context + Surviving Line Prefix + High-Res Ghost Crop] -> [Severed Ending]`.
4. **Forensic Multimodal Prefix Fusion:** Integrated `resnet34` Local Forensic Eye projecting 32 spatial visual tokens directly into `t5-small` cross-attention memory.
5. **Calibrated Margin-Aware Line Splitting:** Replaced whole-page width proportional splitting with ink-band column detection (`_split_line_calibrated` in [`dataset_generator.py`](file:///c:/Users/prave/Downloads/DL/burn/dataset_generator.py)), aligning text cuts with physical edge pixels.
6. **Physical Length-Budget Grounded Decoding:** Integrated character budget capping and 2-gram repetition suppression in `model.generate()`, bounding runaway insertion errors.

5. **Self-Contained Metrics:** Pure-Python CER, Levenshtein, Token Accuracy, ROUGE-L, and Chen & Cherry smoothed BLEU in `metrics.py`.
