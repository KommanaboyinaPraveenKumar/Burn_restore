# Archive

Material from the earlier 6-page prototype, kept for reference only. That
prototype's checkpoint was essentially untrained, so **none of the numbers here
are current**; the main [README](../README.md) §5 has the evaluated results.

- `docs/` — phase reports, audits, model/dataset cards of the prototype
- `reports/` — `report.{tex,pdf,html}`, `PROGRESS_REPORT.md`, session notes
- `legacy_root/` — one-off scripts and ad-hoc test files from the repo root
- `legacy_scripts/` — audit/benchmark scripts that wrote into `docs/`

These scripts are not maintained and may not run against the current code.
